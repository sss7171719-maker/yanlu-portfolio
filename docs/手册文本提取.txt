一、抓数与活动提报第一个是「抓数→报活动→排查」一条龙（插件+内置出表工具），第二个是百补批量提报插件，第三个是把原本要手工逐个导出再拼表的活儿一键搞定。🎯 活动报名一条龙：抓数 → 报活动 → 裸跑排查抓数（底表抓取助手插件）：在京东后台抓取 7 类数据——商品底表、广告底表、百补已提报、券下已提报、官直已提报、秒杀已提报、便宜包邮已提报，刷新要取数的页面即可。多广告子账号可自动免密切换逐个抓（打开采销工作台采销账号管理页面）、累积合并；券支持搜索合并；商品列表支持多次搜索结果合并。报活动（内置的活动报名出表工具）：三个活动共用一个工具，上传底表后自动匹配、算价、卡毛利，按每个活动的模板产出可直接上传的报名表。点插件里的「打开活动报名工具」→ 顶部绿条「导入并刷新」把抓来的底表导进去，然后：若不采用插件抓数可自行先在「基础数据」区上传商品底表、广告底表（跨活动共用，只传一次）选活动 → 上传该活动的可报名表 → 配价格带规则 → 预览 → 导出报名上传表可选：开启「控价清单 / 百补清单」黑名单，命中的 SPU 整组剔除不报名裸跑排查：报完活动后，点工具里的「裸跑排查」，一键看出哪些在架 SKU 在 广告 / 百补 /券 / 官直 / 秒杀 / 便宜包邮 六类活动扶持里一个都没占上（=裸跑品），并按「只缺某一类」分组，方便针对性补报。小知识：促销价 = 京东价×(1−力度%) 与 系统建议价 取较低值；广告品默认卡 30% 毛利、非广告品 10%（可改）。/💰
