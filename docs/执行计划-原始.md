## 设计系统（严格对齐 goonsdesign）

参考站实测要点（执行时对照原站）：

- **字体**：中文 `Noto Sans SC`（简体；参考站用 Noto Sans TC）；英文/数字 `Manrope`
- **主色**：品牌蓝 `#194BFE`（rgb(25,75,254)）；文字近黑；背景浅灰白 `#F4F6F8` / 白
- **按钮**：胶囊形 `border-radius: 100px`，主 CTA 蓝底白字；次级描边圆钮
- **导航**：左品牌字标 + 右「联系我」胶囊 + 圆形汉堡菜单；滚动后轻微毛玻璃
- **排版**：超大标题、大量留白、中英混排小节（如 `OUR WORKS` / 中文副标）；段落短、层级清晰
- **禁止**：旧项目的奶油底 + 珊瑚粉 blob 主视觉；勿做成卡片堆叠仪表盘感

### 必须实现的交互（参考站同级）

用 CDN，不引入 Nuxt/构建链：

1. **Lenis** 丝滑滚动（`html` 带 `lenis` 类）
2. **slideUp / slideUpEach**：区块进入视口上浮渐显（IntersectionObserver 或 GSAP ScrollTrigger）
3. **横向 Marquee**：技能/工具名跑马灯（如 Cursor / Sora / 底表抓取…）
4. **数字 Counter**：关键指标滚到可见时计数（如 `10+` 工具、`50万+` 播放）
5. **Hero 动态文字轮播**：大字轮换关键词（如「广告产品 / AI 提效 / 电商视频」），参考 goons 的「APP设计 / 网站设计…」叠字效果
6. **案例区 hover**：大图微缩放 + 指标条浮现；整卡可点「探索更多」锚到详情
7. **WORKFLOW 式步骤条**（可选用于「我如何做提效」）：01–0N 横向/纵向步骤
8. **移动端**：汉堡全屏菜单；触控友好间距

动效库建议：`lenis` + `gsap` + `ScrollTrigger`（CDN）。至少做满 3 类有意动效，避免杂乱粒子/光晕。

## 飞书视频流水线（执行顺序）

```
用户 Chrome 登录飞书 → 打开飞书 wiki → 自动下载 mp4 → 写入 assets/videos（规范命名）→ 页面自动挂载
                         ↓（失败）
                   用户手动导出 mp4 → 放入 assets/videos → 页面自动挂载
```

### 优先：自动下载

1. 用户在 Chrome 登录飞书网页版。
2. 打开文档：https://nxh7r558yue.feishu.cn/wiki/AIiFwlJt5isfehkhE9nc56Sunic
3. 执行方用浏览器工具/网络面板定位视频真实媒体 URL（`m3u8`/`mp4`），批量保存到 `assets/videos/`，按上表命名。
4. 若为 HLS：用 `ffmpeg` 转封装为 mp4（需本机有 ffmpeg）。
5. 下载后刷新本地站点，确认每个卡片可播。

### 兜底：手动导出

用户从飞书导出/另存 mp4 → 放入 `assets/videos/` → 页面按文件名自动挂载（无需改 HTML）。`README.md` 写清命名表。

## 技术实现约束

- **纯静态**：单入口 `index.html`；CSS/JS 拆分；Google Fonts 可外链（另备系统字体回退）
- **无后端**；视频本地相对路径
- **响应式**：桌面优先，断点约 1024 / 768
- **无障碍**：按钮可聚焦、`prefers-reduced-motion` 减弱动效、图片写 `alt`
- **隐私**：简历电话/邮箱按简历原文展示（求职用途）；不要提交到公开 git 除非用户要求
- **不要**复用旧项目那套奶油+珊瑚 blob 主视觉；色彩与交互以 goons 为准

1. **建目录** `yanlu-portfolio`，初始化上述结构与 README。

## 风险与对策

| 风险 | 对策 |
|------|------|
| 飞书视频鉴权/HLS 难下 | 用户登录配合；失败手动导出 mp4 |
| 视频体积过大 | 控制码率或只嵌代表作 6–8 条，其余链飞书 |
| 手册截图分辨率不足 | 优先用 `hires/` 与手册页图；必要时从 docx 再导出 |
| 纯静态无法 100% 复刻 Nuxt 细节 | 对齐视觉语言与核心动效，不抄业务文案 |
